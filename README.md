# 📚 Resumo Geral das Disciplinas: Semestre 

Este documento compila as competências, tecnologias e metodologias abordadas nas aulas de IoT, Engenharia de Requisitos, Programação e Sistemas Operacionais.

---

## 1. 🌐 Internet das Coisas (IoT)
*Integração entre o mundo físico e o digital.*

- **Hardware:** Foco em ecossistema **Arduino** (Uno/Nano/ESP32).
- **Linguagem:** Desenvolvimento de Firmware em **C++** e Scripts de Integração em **Python**.
- **Conceitos:** Leitura de sensores, controle de atuadores, comunicação serial e protocolos de rede.

## 2. 📋 Levantamento de Requisitos
*A base para o sucesso de qualquer software.*

- **Elicitação:** Técnicas de **Brainstorming**, entrevistas e observação.
- **Documentação:** Diferenciação entre **Requisitos Funcionais (RF)** e **Não Funcionais (RNF)**.
- **Processos:** Criação de **Diagramas** (UML/Fluxogramas) e escrita de **Relatórios Técnicos**.
- **Design:** Uso de **Prototipagem** (Baixa e Alta fidelidade) para validação com stakeholders.

## 3. 🐍 Linguagem de Programação
*Desenvolvimento de software profissional e escalável.*

- **Tecnologia:** Domínio da linguagem **Python**.
- **Clean Code:** Aplicação de nomes significativos, funções coesas e o princípio DRY (*Don't Repeat Yourself*).
- **Versionamento:** Fluxo de trabalho com **Git** (init, commit, push/pull) e colaboração via **GitHub**.
- **Gestão:** Organização de projetos e boas práticas de arquitetura de código.

## 4. 🖥️ Sistemas Operacionais (SO)
*Entendendo como o software gerencia o hardware.*

- **Estrutura:** Estudo do Kernel, chamadas de sistema e drivers.
- **Gerenciamento:** Administração de **Processos**, Threads e hierarquia de **Memória**.
- **Terminal:** Operação via linha de comando (**Shell/Bash**) para automação e permissões de arquivos.
- **Arquivos:** Entendimento de sistemas como NTFS, EXT4 e gerência de Entrada/Saída (I/O).

---

## 🚀 Trilhas de Aprendizado Cruzado
*Como as matérias se conectam:*
- **IoT + Programação:** Criar scripts Python que processam dados do Arduino.
- **Requisitos + SO:** Entender requisitos de desempenho para garantir que o SO suporte a aplicação.
- **Git + Tudo:** Todos os projetos de todas as matérias devem ser versionados no GitHub.
